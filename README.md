# Port Operations Simulator

A compact berth-allocation simulator for exploring vessel arrival queues and service-time scheduling.

## Implemented
- vessel arrival/service model
- multiple berth availability
- greedy earliest-available berth assignment
- waiting-time calculation
- utilization summary
- deterministic tests

## Scope
Synthetic scheduling only. No claim of a real port digital twin, terminal operating system integration, AIS feed, or production optimization.
